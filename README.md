## 🚀 What I do at Jugnoo

**Customer app — native to Flutter, then white-label**

- Rebuilt the ride-hailing customer app in Flutter as a **white-label platform**; live apps such as **Eco Taxi** and **Confiance** ship from one codebase on Android and iOS.
- **Config-driven apps:** branding, feature flags, environments and API settings come from configuration, so a new client doesn't need a fork.
- **Real-time driver tracking** over WebSockets, with smooth vehicle movement on the map.
- **Two map SDKs** (Google Maps and 2GIS) chosen per client, behind one interface.
- **Localisation without app releases:** versioned JSON strings updated from the backend.
- **BLoC + Clean Architecture** and a reusable design system, so features stay modular and consistent across apps.
